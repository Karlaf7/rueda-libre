Justificacion de controles del formulario:

Numero de documento: input type="text", elegí este campo, porque este dato no es una cantidad numerica sino un identificador, puede tener letras.
Tipo de plan y recorrido: select, use lista despegable, porque el cliente debe elegir una sola opcion entre varias.
Aceptación de políticas: input type="checkbox" con required, utilicé una casilla porque la aceptación de las políticas es una respuesta de sí o no, se acepta o no se acepta. Al añadir el atributo required, se impide enviar el formulario si la casilla no está marcada, para asegurar que el cliente acepto las politicas antes de reservar

Comprobación de herencia en DevTools:

En DevTools revisé un párrafo de mi index.html. 
La propiedad font-family sí se hereda: el párrafo no la tiene escrita, pero en Computed aparece Open Sans, que puse en el body. 
En cambio, margin no se hereda: el párrafo tiene 16px de margen que vienen del navegador, no del body.


Abrí DevTools en el enlace de la página actual, que tiene la clase activo, y vi en Styles que el color de .activo salía tachado.
El que ganaba era el de #menu a, por eso el enlace se veía gris y no verde. El font-weight: 600 sí se aplicaba porque #menu a no lo define.

Especificidad de cada selector:
#menu a = (1, 0, 1), porque tiene 1 id y 1 elemento.
.activo = (0, 1, 0), porque tiene 1 clase.

Causa: las dos reglas cambian el color del mismo enlace y el navegador se queda con la de mayor especificidad.
Un id pesa más que una clase, así que #menu a gana aunque .activo esté escrita después en el archivo.


Ancho total de una tarjeta antes y después de cambiar box-sizing:
Medí el ancho de una tarjeta en Computed con width: 20rem (320px). Con content-box, 
el contenido medía 320px y el ancho total era 354px (320 + 32 de relleno + 2 de borde), es decir, 
la tarjeta se hacía más ancha que lo declarado. Con border-box, el ancho total fue 320px y el contenido se redujo a 286px, 
porque el ancho ya incluye relleno y borde.


Resumen:
En esta semana construí el sitio web de Rueda Libre, un negocio de alquiler de bicicletas en Medellín, con tres páginas: 
inicio, tarifas y reservas. Primero armé la estructura en HTML con etiquetas semánticas, imágenes, listas, tablas de precios y un formulario con validaciones. Luego le di estilo con CSS usando variables para los colores y las fuentes, además de un menú con estados de hover y foco. 
En el último reto usé position para poner la etiqueta “Nuevo” en la tarjeta de bicicletas eléctricas y un botón de WhatsApp fijo en la esquina inferior derecha, y organicé el styles.css por secciones con comentarios. También revisé el sitio con DevTools para buscar errores y probé el teclado, y al final publiqué la versión 1.0 en GitHub Pages. 
Lo que mejoraría es hacer la página adaptable para celulares, conectar el formulario para que envíe las reservas de verdad, revisar los precios con el cliente y poner el número real de WhatsApp.
